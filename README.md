# go-tokenize

中英文分词和词频统计，零依赖只用标准库。

看一篇文章里哪些词出现得多、常见搭配是什么，或者统计代码里的标识符频率，都能用。

## 编译

```
go build -o go-tokenize.exe
```

## 用法

```
> go-tokenize -top 5 -stop article.txt
go       │██████████████████████████████ 142 (8.31%)
函数     │████████████████████ 95 (5.56%)
接口     │█████████████ 61 (3.57%)
...

共 1709 个词，483 种
```

中文按两字一组切（比单字更有意义）：

```
go-tokenize -cjk 2 -top 15 中文.txt
```

看常见的两词搭配：

```
go-tokenize -ngram 2 -top 10 en.txt
```

只要一个概览：

```
> go-tokenize -sum article.txt
字符 5231（其中中日韩 3120）  字节 11894  行 87
词数 1709  不重复 483  重复率 71.7%
```

也能从标准输入读：

```
type article.txt | go-tokenize -stop -min 2
```

## 参数

| 参数 | 默认 | 说明 |
|------|------|------|
| `-lower` | true | 统一转小写 |
| `-min` | 1 | 少于这么多**字符**的词丢掉 |
| `-stop` | false | 过滤内置的中英文停用词 |
| `-stopfile` | | 从文件读停用词，一行一个，`#` 开头是注释 |
| `-cjk` | 1 | 中日韩文字按几个字一组切 |
| `-ngram` | 0 | 统计 n 个相邻词的组合 |
| `-top` | 20 | 只显示前几个，0 表示全部 |
| `-sum` | false | 只输出统计概览 |

## 实现上注意的几点

- **`-min` 按字符数算不是字节数**。中文一个字是 3 个字节，按字节算的话 `-min 2` 会把所有中文单字全留下、把所有英文短词全滤掉，完全反了。
- **词内的 `'` 和 `-` 要保留**：`don't`、`well-known` 是完整的词。但结尾的不算，`boys'` 里的撇号要切掉。
- **开了 `-lower` 时停用词也得转小写**再匹配，不然停用词表里写 `The` 就永远匹配不上已经转成小写的 `the`。
- **空的停用词条目要跳过**。停用词文件里有空行的话，不处理会导致空字符串进了停用词集合。
- **CJK 分段比 gram 长度短时不能吞掉**。`-cjk 3` 遇到只有两个字的一段，滑动窗口一次都进不去，得整段当一个词。
- **相同词频时按字典序排**，不然每次跑输出顺序都不一样（Go 的 map 遍历是随机的）。
- **日文假名和韩文谚文也按 CJK 处理**，不是只认汉字。
- **结尾的换行不多算一行**。
